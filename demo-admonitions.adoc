== Multi-Paragraph Admonitions

[NOTE]
====
This is the first paragraph of a multi-paragraph note.

This is the second paragraph with more details.

* A list item inside an admonition
* Another list item
====

[DEFINITION]
====
A *definition* can span multiple paragraphs.

NOTE: A NOTE admonition within another admonition.

[EXAMPLE]
=====
Can even be a block-style admonition within another admonition.

With several paragraphs.
=====

The second paragraph can provide further elaboration or examples.

 A literal block inside a definition admonition.
====

== Collapsible Admonitions

TIP%collapsible%open: This tip starts open and can be collapsed.

[WARNING%collapsible]
.Click to see the warning
====

[EXAMPLE%collapsible%open]
=====
Can even be a block-style admonition within another admonition.

This one is open.

.Should be closed by default
======
Can even be a block-style admonition within another admonition.
======

=====

====
