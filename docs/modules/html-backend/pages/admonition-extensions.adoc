= Extended Admonition Features

For a compact, author-focused guide, see xref:admonition-quickstart.adoc[Admonition Extensions Quickstart].

== Description of the Purpose: What Was Added

The standard Asciidoctor behavior was extended with configurable admonition functionality.
The goal is to support project-specific admonition types while keeping the standard types fully compatible.

The following capabilities were added:

* Configurable admonition type registry (`admonition-types` and per-type attributes)
* Custom admonition tags, labels, and DocBook mappings
* Strict validation with warnings (invalid entries are skipped, conversion continues)
* Collapsible admonitions using `%collapsible` and `%open`
* Per-type counters and automatic anchors for each admonition occurrence
* Admonition index macro (`admonition-table::type[]`) rendered as a link list
* Styling hooks for custom icons and fallback text icons


== Description How the New Features Can Be Used on an adoc Page

=== 1. Declare the active admonition types

[source,asciidoc]
----
:admonition-types: note,tip,important,warning,caution,example,definition
----

=== 2. Configure each custom type

[source,asciidoc]
----
:admonition-example-tag: EXAMPLE
:admonition-example-label: Example
:admonition-example-backend-docbook: note

:admonition-definition-tag: DEFINITION
:admonition-definition-label: Definition
:admonition-definition-backend-docbook: note
----

=== 3. Use admonitions (paragraph and block style)

[source,asciidoc]
----
EXAMPLE: Paragraph-style custom admonition.

[DEFINITION]
====
Block-style custom admonition.
====
----

=== 4. Use collapsible admonitions

Paragraph style:

[source,asciidoc]
----
NOTE%collapsible: Hidden by default.
TIP%collapsible%open: Open by default.
----

Block style:

[source,asciidoc]
----
[WARNING%collapsible]
.Click to see details
====
Warning content.
====
----

Summary text priority for collapsible admonitions:

. block title (for example `.Click to see details`)
. document attribute `admonition-collapsible-label`
. fallback `Details`

=== 5. Insert admonition index lists

[source,asciidoc]
----
admonition-table::note[]
admonition-table::example[title="List of Examples"]
admonition-table::definition[]
----

Current behavior of this macro:

* Renders a list (not a table)
* Each list entry links to the generated anchor of the admonition
* Entry text uses admonition title if present
* If no title is present, entry text falls back to `{Label} {Number}`


== Description How Custom (and the Standard) Admonitions Can Be Added

=== Standard types

The standard types are still available by default:

* `note`
* `tip`
* `important`
* `warning`
* `caution`

If `admonition-types` is not set, these defaults are used.

=== Add a custom type

To add a type named `hint`:

[source,asciidoc]
----
:admonition-types: note,tip,important,warning,caution,hint
:admonition-hint-tag: HINT
:admonition-hint-label: Hint
:admonition-hint-backend-docbook: tip
----

Then use it in content:

[source,asciidoc]
----
HINT: Remember to cache this response.

[HINT]
====
This can also be used as a block admonition.
====
----

=== Validation rules

Configuration is validated strictly:

* Type name format: `^[a-z][a-z0-9_\-]*$`
* Tag format: `^[A-Z][A-Z0-9_]*$`
* Tag must be unique across all configured types
* DocBook mapping must be one of: `note`, `tip`, `important`, `warning`, `caution`

Invalid entries are skipped and warnings are logged.


== Description How the Rendering Can Be Influenced by the Stylesheets

Rendering can be customized in both:

* `src/stylesheets/asciidoctor.css` (source stylesheet)
* `data/stylesheets/asciidoctor-default.css` (generated default stylesheet)

=== Custom icon example

The default stylesheet includes icon rules for standard types and an explicit rule for `example`:

[source,css]
----
.admonitionblock td.icon .icon-example::before {
  content: "\f02d";
  color: #007a70;
}
----

=== Fallback icon text for types without a dedicated icon

If no custom icon glyph is configured, the icon cell displays the admonition label text.
The fallback is styled to stay on one line:

[source,css]
----
.admonitionblock td.icon i.fa[class*="icon-"]...
{
  content: attr(title);
  white-space: nowrap;
  word-break: normal;
  overflow-wrap: normal;
}
----

This keeps the fallback text unbroken and keeps content aligned to the right of the icon column.

=== Collapsible admonition rendering

Collapsible admonitions are rendered as normal admonition layout (icon + content), with an inner `<details>` in content.
The expand/collapse indicator is controlled by the standard `details > summary` CSS rules.


== Description of the Tests

Test coverage is primarily in:

* `test/blocks_test.rb`
* `test/lists_test.rb`

Covered scenarios include:

* Parsing and rendering of custom admonition types
* Label precedence behavior (`caption` and configured labels)
* Validation warnings for invalid names, tags, duplicates, and DocBook mappings
* DocBook fallback behavior for missing/invalid mappings
* Collapsible admonition options (`%collapsible`, `%open`) in paragraph and block style
* Integration with list continuation scenarios

Notes:

* There are no dedicated tests yet for `admonition-table::...[]` output format.
* Behavior is currently verified in manual demo output (`demo-admonitions.adoc` / `demo-admonitions.html`).


== Detailed Description of the Changes/Additions to the Source Code

=== Core constants and defaults

File: `lib/asciidoctor.rb`

* Added `ADMONITION_TYPES` as a configurable default registry
* Added `DOCBOOK_ADMONITION_TAGS` validation set
* Kept compatibility constant `ADMONITION_STYLES`

=== Document-level admonition registry and cache

File: `lib/asciidoctor/document.rb`

* Added parsing and lookup APIs:
** `parse_admonition_paragraph`
** `admonition_type_for_tag`
** `admonition_type_for_name`
** `resolve_admonition_textlabel`
** `resolve_admonition_docbook_tag`
* Added cached registry refresh:
** `refresh_admonition_types`
* Added per-type counters and catalog:
** `register_admonition_occurrence`
* Added cache invalidation on relevant attribute changes

=== Parser integration

File: `lib/asciidoctor/parser.rb`

* Replaced static admonition checks with document registry lookups
* Added support for options appended to admonition tags in paragraph form (`%collapsible`, `%open`)
* Added support for `admonition-table::...[]` block macro
* Creates `:admonition_table` block nodes with parsed attributes

=== Regex for admonition index macro

File: `lib/asciidoctor/rx.rb`

* Added `BlockAdmonitionTableMacroRx` for parsing `admonition-table::type[]`

=== HTML converter changes

File: `lib/asciidoctor/converter/html5.rb`

* `convert_admonition`
** supports collapsible/open options
** keeps icon+content admonition layout
** renders inner details/summary for collapsible content
* `convert_admonition_table`
** resolves entries from document admonition catalog
** renders list-based admonition index with links

=== DocBook converter changes

File: `lib/asciidoctor/converter/docbook5.rb`

* `convert_admonition`
** resolves configured DocBook mapping per type
** falls back to `note` with warning if mapping is missing/invalid

=== Locale defaults

File: `data/locale/attributes.adoc`

* Added default admonition-type attributes for standard types

=== Stylesheet extensions

Files:

* `src/stylesheets/asciidoctor.css`
* `data/stylesheets/asciidoctor-default.css`

Changes include:

* custom icon rule for `example`
* text fallback icon styling for custom types without explicit icon
* no-wrap fallback behavior
* collapsible details summary styling alignment with admonition content
